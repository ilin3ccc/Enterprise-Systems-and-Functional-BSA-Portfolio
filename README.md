# Enterprise Systems & Functional BSA Portfolio

## Overview
This repository showcases end‑to‑end business systems analysis (BSA) and process re‑engineering work. Each project demonstrates structured problem diagnosis, workflow modeling, and future‑state design aligned with enterprise operational goals.

## Project Details

### **Project 1: ICU Early Warning System (EWS) — Process Mapping**
Redesign of a legacy ICU triage workflow into an automated Early Warning System to reduce clinical latency and improve coordination.

**Key Deliverables**
- Current‑state and future‑state **[Swimlane](ca://s?q=Explain_swimlane_diagrams)** and **[BPMN](ca://s?q=Explain_BPMN_2.0)** diagrams  
- **[Bottleneck Analysis](ca://s?q=Explain_bottleneck_analysis)** identifying structural delays  
- **Future‑State Solution Narrative** detailing system logic and outcomes
